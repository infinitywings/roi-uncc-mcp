## Project Architecture

### Core Components

1. **MCP Server** (`/mcp-server/src/server.py`)
   - Flask REST API on port 5000
   - Bridge between AI models and grid simulation
   - Exposes 10 attack primitives

2. **HELICS Federation**
   - Real-time co-simulation platform
   - Synchronizes GridLAB-D and GridPACK
   - Message-based communication protocol

3. **Grid Simulators**
   - **Transmission**: IEEE 9-bus system (GridPACK)
   - **Distribution**: 2x IEEE 123-node systems (GridLAB-D)
   - **EV Infrastructure**: 6 charging stations per distribution system
   - **Controller**: Python-based peak demand management

4. **Attack Engine** (`/mcp-server/src/attacks/attack_engine.py`)
   - Implements all attack primitives
   - Parameter validation and safety constraints
   - Techniques: spoof_data, inject_load, reconnaissance, block_command

5. **AI Integration** (`/mcp-server/src/ai/local_llm_client.py`)
   - Supports OpenAI, Anthropic, Ollama
   - Current model: openai/gpt-oss-120b (120B parameters)
   - Strategic attack planning and execution

### Docker Architecture
- **Base Image**: `roi-img:latest` (HELICS, GridLAB-D, GridPACK)
- **MCP Image**: `roi-uncc-mcp:latest` (MCP server)
- **Network Mode**: host (required for HELICS)
